## 💻 How to Run Locally

Since the portfolio uses **ES Modules** (`type="module"`), run a local HTTP server:

```bash
# Python 3
python3 -m http.server 8080

# Or using Node npx
npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
